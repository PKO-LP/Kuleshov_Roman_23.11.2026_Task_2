# Игра «Угадай число»

Простая консольная игра на Python. Программа по очереди загадывает два числа от 1 до 105, а игрок должен их отгадать.

## Как это работает
Программа дает подсказку о диапазоне загаданных чисел (от 1 до 105).
Игрок вводит число в консоль, а программа отвечает: «Больше!» или «Меньше!».
В игре спрятаны две секретные пасхалки: `six seven` и `Бибирево это район бобров`.
После угадывания выводится количество потраченных попыток.

## Как запустить
Убедитесь, что на компьютере установлен Python 3.
Откройте терминал в папке с файлом `app.py`.
Введите команду:
```bash
python app.py
```
